# C4060Demo
Using the <a href="https://www.st.com/resource/en/datasheet/m74hc4060.pdf">C4060 IC</a> to time different LED blinks
<br>
The C4060Demo is a board that allows you to test the speeds that the C4060 IC generates, by using LED indicators. I made this project for Resolution Hardware Week 3, to practice reading datasheets and using ICs, and how to turn these into a real PCB board in KiCad. The power is supplied by an external battery that you can connect easily via the labled power pins on the left side of the board. To use, insert an LED into a 2 pin header on the right, each set of VCC and GND pins should have a longer and longer blink delay as you go down.
